
## Setup and Run

**Platform:** Android  
**Framework:** Flutter  
**Language:** Dart

### Requirements
- Flutter SDK
- Android Studio or VS Code
- Android device or emulator

### Build and Run

Open the project folder in the terminal and run:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

### Build APK

To generate a debug APK:

```bash
flutter build apk --debug
```

APK location:

`build/app/outputs/flutter-apk/app-debug.apk`
